Now do these three things

  1. Paste it into an AI builder, and attach the pictures above. Claude, Gemini or ChatGPT. Ask for one single HTML file so there is nothing to install.
  2. Put it online free. Drag the file onto cloudflare.com/drop for a one hour preview, or into Cloudflare Pages for a permanent free address.
  3. Show it to one real visitor. A parent, a student, a colleague. Watch where they hesitate, then fix that one thing.

Before you call it finished

  • The four pages all work and the top bar is the same on every one.
  • Every picture has alt text, so a blind visitor knows what it shows.
  • It reads well on a phone held in one hand.
  • The title and description are written for search, not left as Untitled.
  • The contact button really opens email or WhatsApp.
