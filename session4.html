Stage 1 · Planning and interviewing

Do not prompt until the game has a job.

Pair up. One teacher is the client; the other is the game designer. Ask, listen and write decisions—not features.

The seven-minute interview

  1. Who will play, and what is their level?
  2. What single skill should the game drill?
  3. What should count as a correct answer?
  4. What should happen after success or failure?
  5. Where will the game be used and shared?
  6. Which visual identity must appear?

Turn the interview into a design brief

Your interview brief will appear here.

Facilitator move: ask each pair to remove one unnecessary feature. A clear learning loop is stronger than a crowded game.

Stage 2 · Creating the game

Prompt from decisions, then build in small passes.

The master prompt below is complete enough to recreate this game. Teachers customise only the learner, subject, questions, answers, colours and avatar.

A

Give context

State the learning level, objective, device and offline requirement.

B

Specify behaviour

Describe every click, turn, reward, snake, ladder and winning condition.

C

Constrain the output

Require one self-contained HTML file with no external dependencies.

A safe four-pass build

  1. Pass 1 · Board and movementConfirm 20 squares, alternating path, dice and exact-finish rule.
  2. Pass 2 · Modes and playersAdd computer mode, 2–5 local players, names, colours and turn order.
  3. Pass 3 · Questions and trophiesMake all square numbers clickable, save question pairs and award one trophy per square.
  4. Pass 4 · Delight and accessibilityAdd 3D dice, sounds, confetti, keyboard focus, responsive layout and reduced-motion support.

Stage 3 · Testing and reviewing

Test the loop, not only the look.

Work in teams of three. Each reviewer uses a different lens, then the creator fixes only the issues that block learning or play.

Learner lensCan I understand what to click without explanation?
Teacher lensCan I change names, questions and mode quickly?
Technical lensDoes every button work offline on a second device?
